# durable-writes.txt: the table of the durable write census (durable-writes.awk, run by
# durable-writes.test.ts). Every line holds four tab separated fields: the kind, the file, a
# subject, and the rest.
#
# Names (scratch by rule, judged as durable-writes.awk says):
#   scratch  <file> <NAME or F:NAME> <reason>  a scratch variable of the file (F: inside function
#            F alone); every assignment of it in a scope it roots is judged
#   from     <file> <NAME> <source files>      a variable the file takes from a sourced file,
#            where it must be a scratch variable proven by assignment
#   operand  <file> <F:N> <reason>             function F writes into its operand N (or @ for
#            every operand); every call of F in every walked file judges that operand
#   bound    <file> <N, NAME, or F:NAME> <reason>   a path the caller names that the line reader
#            cannot follow (a script's own operand, an environment value its caller exports, a
#            path read out of a file the caller wrote); taken on its reason, never judged
#
# The allow list (every other write outside the store, by its exact line text):
#   <class>  <file> <reason> <the line as written>
#   store         each driver's own storage, written by the driver code and its package hooks
#   config        the workspace configuration, through the configuration library's locked writer
#   laws          the generated law layer, through the composer
#   overlay       the package overlay: the extension tree, the install records, the stashed
#                 uninstall hooks, the kept declarations, and the install stage
#   backups       the sweep and move backups: the posix sweep, the move engine, and a driver
#                 hook's backup of its own storage
#   graph         the ast-doc-graph graph database and its caller owned cache folder
#   payload       the installer's payload placement: the drawer code, the catalog, the loader
#   tmp-fallback  the system temp fallback scratch takes when the drawer cannot hold it, on its
#                 assignment lines alone
#
# A dead entry (a name or a line the census never meets) reads red, so an edit to a listed
# line or a removed writer updates this table in the same change.
