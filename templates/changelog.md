# changelog grammar

Keep a Changelog format; sections newest first; conventional prose, humans
and agents are the audience; zero em-dashes.

## [X.Y.Z] - YYYY-MM-DD

### Added

- <one change per line, prose: what and why in one sentence>

### Changed

- <...>

### Fixed

- <...>

# the section is appended at the ship breath, the same breath as the tag
# (AGENTS.workspace.md @git: commit + push + tag + section, one act)
# every commit in the tag range appears in the section
# retroactive sections are lane-drafted from the record; see RECORD_COMPLETENESS
